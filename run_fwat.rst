How to run FWAT?
==================

There are four basic steps to do the iterative inversion using our FWAT package.

Preparing input files
---------------------

Before running any iteration, the users should write their own scripts to make \textbf{data} and \textbf{src{\_}rec} in the format described above. The corresponding example scripts are \textit{generate{\_}data .bash} and \textit{mk{\_}forcesolution.bash}.
